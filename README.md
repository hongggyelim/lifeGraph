## 개발 환경

Vite + React 19 + TypeScript

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm run build    # 타입 체크 후 dist/ 에 빌드
npm run preview  # 빌드 결과 미리보기
npm test         # 단위 테스트 (Vitest)
npm run lint     # ESLint
```
